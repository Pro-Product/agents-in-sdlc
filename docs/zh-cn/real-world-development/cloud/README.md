**[GitHub Copilot 云智能体](https://docs.github.com/copilot/concepts/agents/cloud-agent/about-cloud-agent)** 可在云端异步工作。你在 GitHub 上分配任务后，云智能体便会在后台接手，探索存储库、进行更改并创建拉取请求，你则可以继续处理其他工作。

本系列练习将添加云智能体要遵循的自定义指令，然后分配一个 GitHub issue 并让它实现任务。你将审查并使用自定义智能体来塑造其工作方式，在智能体仪表板中监控并引导会话，最后审查它创建的拉取请求并迭代改进结果。

## 先决条件

参加本工作坊前，请确保具备以下条件：

- [ ] 拥有有效的 **Copilot Student、Pro、Pro+、Business 或 Enterprise** 计划的 GitHub 帐户
- [ ] 已为帐户或组织启用 Copilot 云智能体

> [!TIP]
> 没有付费计划？通过 [GitHub Education][callout-student-plan-education] 验证身份的学生可免费使用 GitHub Copilot。**Copilot Student** 计划包含本工作坊使用的智能体、MCP、代码审查和 Copilot CLI 功能，可用于完成所有工作环境的练习。

[callout-student-plan-education]: https://github.com/education/students

> [!NOTE]
> Copilot Student、Pro、Pro+、Business 和 Enterprise 均可使用云智能体；只有 Copilot Free 计划不包含此功能。Copilot Business 或 Enterprise 组织需要管理员启用云智能体。

> [!NOTE]
> 本工作环境不涉及 MCP。若要了解如何将 MCP 服务器与 Copilot 配合使用，请参阅 [CLI 工作环境][cli-harness]或 [VS Code 工作环境][vscode-harness]。
